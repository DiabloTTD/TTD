# TTD - Torchlight Infinite

**토치라이트 인피니티 플레이를 더욱 편리하게!**

TTD는 토치라이트 인피니티 유저들을 위한 비공식 게임 편의 도구 및 정보 서비스입니다.

게임 플레이에 필요한 다양한 정보와 편의 기능을 제공하여 더욱 효율적인 게임 환경을 지원합니다.

![TTD 대표 이미지](images/ttd-banner.png)

---

## 주요 기능

- **게임 편의 기능** — 다양한 게임 콘텐츠를 더욱 편리하게 관리
- **거래소 시세 정보** — 아이템 가격과 시세 변동 확인
- **투자분석** — 거래소 데이터 기반 분석 정보 제공
- **랭킹 정보** — 게임 관련 랭킹 확인
- **지속적인 업데이트** — 기능 개선 및 오류 수정

## 설치 및 이용 안내


★ TTD 처음 사용자님들~ 기능과 메뉴를 모르셔도 됩니다
- 별도 설정없이 TTD 처음 접하시는 분들을 위해 기본셋팅 및 자동으로 되어있습니다
- 아래 사용방법만 숙지하시고 이후 숙달되시면 그때 천천히 TTD기능을 하나씩 배워 가시면됩니다

1. 최신 버전 ZIP 파일을 다운로드합니다.

2. 파일을 원하는 폴더에 압축 해제합니다.

3. 토치라이트(스팀/전용클라)선택해서 실행을 합니다.

4. 캐릭터를 선택하고 마을에 입장합니다

5. ESC키 > 기타설정 > 로그오픈(log open) 클릭 합니다 (로그아웃 아닙니다.)

6. TTD.EXE 를 실행합니다

7. 캐릭터가 마을에 있는상태에서 TTD에 초기화 버튼 클릭 합니다

8. 가방 정렬 버튼 1회 클릭 합니다. (3번째 가방 정리 추천)

9. 사냥 시작 (용자런,이계런,보스런,차원 등등)
